One museum label under 200 characters: the label a museum in the year 3000
puts beside an ordinary object from today — a CAPTCHA.

> CAPTCHA, c. 2025. Proof of humanity: distorted letters only a human could read, which humans failed daily.

## Why this line

It reads like a real museum label — deadpan, dated "c. 2025", confident —
and the humour comes from the year 3000 getting the object both right and
wrong at once. The CAPTCHA really was a test that proved you were human,
and its letters really were only readable by a human — yet the punchline,
"which humans failed daily", is also true: everybody has failed a CAPTCHA.
The misreading is the label treating a daily annoyance as a solemn proof of
humanity, and the laugh lands on the last two words, on the first read, with
no explanation. The object is fresh — not the fork, the parking meter, the
house key or the group chat from the brief — and nothing in the line could
have been written for any other object.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–200 characters, single line, not whitespace-only) and a
byte-exact read-back verification.
